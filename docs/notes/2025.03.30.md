# Kalibr calibration

I am going to use [Kalibr](https://github.com/ethz-asl/kalibr) to calibrate the camera. I decided not to calibrate IMU for now, because this is a lot of work,
and I am not sure if it is necessary.

Problems:
[ x ] I need to generate and print Apriltag on A4 paper
[ x ] I need to write a launch file for calibration
[ x ] I need to record data from camera and IMU in a bag format
[ x ] I need to convert ROS2 to ROS1
[ x ] I need to write a config file for Kalibr
[ x ] I need to run Kalibr
[ x ] I need to integrate the calibration data into my code

I plan to calibrate using 1080x1920 image resolution, because [this](https://github.com/mtmal/Jetson-Stereo-CSI-Camera) states that "By default I try to capture images at the highest resolution and then resize. Modes that provide lower resolution images but at faster frame rate crop them. This can be seen on the noise. When full-size images are resized, the noise is filtered a little bit so that improves image's quality". I plan to implement an image processing pipeline:
1. Capture grayscale image
2. Use image_proc to rectify and resize image to 640x480 or 320x240
